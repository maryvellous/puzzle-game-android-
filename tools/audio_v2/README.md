# Laboratorio audio storico

Gli script Python e SceneRenderCli sono strumenti di ricerca precedenti al replay completo. Non costituiscono un DSP alternativo o una pipeline attiva. Non utilizzare le vecchie audizioni come requisiti o prove hardware.

Il percorso attivo è `tools/audio_v2_java/RuntimeReplayCli.java` e `DenseSceneCli.java`, eseguiti da [lava-blobs.yml](../../.github/workflows/lava-blobs.yml). Consultare la [specifica audio](../../docs/AUDIO_ENGINE_V2_MATERIAL_BLOOP.md) e lo [stato tecnico](../../docs/TECHNICAL_ROADMAP.md) per configurazione, riferimento e gate. Il vecchio workflow offline e le istruzioni di rigenerazione sono nella storia Git. Non distribuire campioni audio derivati come sound pack.
